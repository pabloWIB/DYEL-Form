Galería de ejemplo

Un portafolio de DYEL se ve así: las piezas que el usuario ha elegido, en cuadrícula. Pulsa cualquiera para verla completa.

Las cinco piezas son recortes de un mismo cartel de Reuel (@reuel.dsgn), usado aquí como material de muestra. La autoría es suya.

DYEL es una demo de interfaz: HTML, CSS y JavaScript sin dependencias ni compilación. No hay servidor, base de datos ni cuentas reales.
